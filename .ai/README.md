# .ai

This folder contains repo-local guides for AI-assisted workflows.

## Purpose

Use this folder for procedural guidance that is easy to miss during repeated implementation work, but does not belong in the main package READMEs or broader repo docs.

These guides are intended to improve consistency and reduce cleanup refactors. They complement normal review, validation, and package-boundary documentation; they do not replace them.

## Structure

- `skills/`: reusable workflow guides for repeated implementation tasks in this repository.

## Current guides

- `skills/design-system-component-workflow`: checklist and boundary guidance for adding or updating Hoite Dev design-system components across `@hoite-dev/ui`, `@hoite-dev/ui-react`, `@hoite-dev/ui-vue`, and the frontend-docs Storybook workspaces.
