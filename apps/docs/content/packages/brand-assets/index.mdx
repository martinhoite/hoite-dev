# `@hoite-dev/brand-assets`

`@hoite-dev/brand-assets` distributes the shared Hoite Dev marks and favicon assets used by docs and related frontend surfaces.

## What this package owns

- Shared logo assets.
- Favicon source files.
- A stable package boundary for consuming brand assets without copying files between apps.
