# `@hoite-dev/diagnostics`

`@hoite-dev/diagnostics` holds small diagnostic helpers and debugging-oriented utilities for the workspace.

## What this package owns

- Shared debugging helpers that do not belong in app code.
- A package boundary for tooling-oriented utilities that may be consumed by multiple apps or scripts.
