# `@hoite-dev/storybook-addon-composition-theme`

`@hoite-dev/storybook-addon-composition-theme` keeps composed Storybook surfaces aligned with the shared theme setup.

## What this package owns

- Storybook addon bootstrap and runtime hooks for theme composition.
- Manager, preview, and preset entry points for the composition theme workflow.
- The package boundary for Storybook-specific theme wiring that should not leak into `@hoite-dev/ui`.
