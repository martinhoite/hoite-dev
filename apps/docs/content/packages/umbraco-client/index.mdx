# `@hoite-dev/umbraco-client`

`@hoite-dev/umbraco-client` is the source-oriented content package for the current Umbraco Delivery API integration.

## What this package owns

- Typed Umbraco client creation helpers.
- Generated OpenAPI transport and doc-type output.
- Public-facing content helpers and policy configuration around exposed document types.

## Why it matters

This package keeps source-specific Umbraco concerns behind a shared content boundary so app code can stay focused on normalized content consumption.
