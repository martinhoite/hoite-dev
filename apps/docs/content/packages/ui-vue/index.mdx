# `@hoite-dev/ui-vue`

`@hoite-dev/ui-vue` provides the Vue component implementations for the Hoite Dev design system.

## What this package owns

- Vue Single File Component implementations for shared primitives.
- Vue-specific runtime behavior layered on top of the shared styling contract.
- Public component APIs for Vue and Nuxt consumers.

## Relationship to `@hoite-dev/ui`

The package keeps Vue implementation details local while inheriting tokens, shared CSS, and docs metadata from `@hoite-dev/ui`.
