# `@hoite-dev/biome-config`

`@hoite-dev/biome-config` is the shared Biome configuration package used across the monorepo.

## What this package owns

- The reusable Biome base configuration consumed by apps and packages.
- A single place to evolve linting and formatting defaults without duplicating repo-wide config.
