# Packages

Workspace package reference for the Hoite Dev docs stack, shared UI system, and supporting tooling.

## What is covered here

- Shared styling and framework packages for the design system.
- Tooling packages that support docs, Storybook composition, diagnostics, and linting.
- Source ownership entry points for the content client and brand asset distribution package.
