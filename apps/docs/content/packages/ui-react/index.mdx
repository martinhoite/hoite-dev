# `@hoite-dev/ui-react`

`@hoite-dev/ui-react` provides the React component implementations for the Hoite Dev design system.

## What this package owns

- React wrappers for the shared primitives.
- Runtime behavior such as clipboard state and framework event handling.
- React-facing public props that stay aligned with the shared styling contract.

## Relationship to `@hoite-dev/ui`

`@hoite-dev/ui-react` consumes the tokens, CSS, docs metadata, and helper exports from `@hoite-dev/ui` instead of redefining the styling contract locally.
