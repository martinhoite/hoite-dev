# Tokens

Theme-aware token reference for the Hoite Dev design system. These values originate in `@hoite-dev/ui` and drive the shared CSS custom properties consumed by the docs site, React components, and Vue components.

## What is shown here

- Full semantic color reference across light and dark themes.
- Primitive palette tokens shown alongside the semantic aliases they support.
- Full exported token groups for layout, z-stack, spacing, radius, size, stroke, motion, and typography.
- Runtime-resolved CSS variable output from the shared theme layer with visual previews tied to the token type.
