# Tokens

Theme-aware token reference for the Hoite Dev design system. These values originate in `@hoite-dev/ui` and drive the shared CSS custom properties consumed by the docs site, React components, and Vue components.

## What is shown here

- Light and dark reference values for the core color surface.
- Representative spacing and typography tokens used most often in product work.
- Runtime-resolved CSS variable output from the shared theme layer with quick visual previews.
