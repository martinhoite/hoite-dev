# CodeBlock

CodeBlock defines the shared shell, header, copy affordance, and overflow behavior for reusable code samples in the Hoite Dev design system.

Syntax highlighting comes from the shared `@hoite-dev/ui` Shiki integration, while the React and Vue packages handle runtime rendering and clipboard state. See [Shiki](https://shiki.style/) for the highlighter itself and the [Shiki theme guide](https://shiki.style/guide/theme-colors) for the theme model the package adapts.

## Purpose

CodeBlock provides a consistent container for readable code samples across docs, demos, and product surfaces without pushing framework runtime behavior into the styling layer.

## Contract highlights

- `code` is the raw source input and remains the copy source of truth.
- `language` drives highlighting metadata and the default visible label.
- `label` intentionally overrides the visible header text when the copy should read more clearly than the raw language token.
- `showCopy` exposes the compact header action, while runtime clipboard state stays in the framework wrappers.

## Usage notes

- The copy action should expose clear visible and announced success states.
- Long code stays horizontally scrollable instead of wrapping unpredictably.
- The outer shell supports a narrow set of passthrough attributes instead of an unrestricted attribute surface.
